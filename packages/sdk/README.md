# @mikata/sdk

The client for `mikatad`: stdio and WebSocket transports, and reconnecting by session. `@mikata/sdk/browser` is the browser's entry.

```sh
npm install @mikata/sdk
```

It needs a running `mikatad`, from [Mikata](https://github.com/Kaginari/mikata). See [the client protocol](https://github.com/Kaginari/mikata/blob/main/docs/04-protocol.md).

Pre-1.0: the API may change between minor versions. MIT.
